🟢 Trilha Secundária: Frontend

Existe para aumentar sua autonomia como Backend Developer. Você não precisa concluí-la para atingir nenhum Gate de Backend (G0–G4). Objetivo: criar uma interface funcional que consuma sua própria API e entender o frontend moderno — não se tornar especialista em React.

Integração Full Stack (extensão, não requisito)

Somente aqui você conecta: React ↓ HTTP ↓ Spring Boot ↓ PostgreSQL — login, listagem, criação, edição, exclusão e tratamento de erros consumindo sua API.

❌ Não é prioridade agora

“Essas tecnologias podem ser importantes depois, mas não devem competir com os fundamentos da sua próxima etapa.” Antes de adicionar qualquer assunto, pergunte (regra de decisão): 1) é necessário p/ Java Backend? 2) aparece em vagas relevantes? 3) ajuda no próximo Gate? 4) tem aplicação prática? 5) é mais importante que o atual?
